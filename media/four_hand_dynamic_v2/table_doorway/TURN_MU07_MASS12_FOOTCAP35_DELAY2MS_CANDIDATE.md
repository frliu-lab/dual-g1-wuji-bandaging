# 双 G1 四只 Wuji 手转桌：2 ms 指令延迟修正候选

在模型桌体 1.197 kg、手面摩擦 0.7、接近阶段预握力提高 10% 的条件下，把转动阶段 WBC 的足底摩擦约束从模型接触值的 50% 收紧到 35%。控制器保持简化的 2 ms 指令延迟；求解失败不得退回宽松求解器。

原 50% 约束版本虽然完成动作并通过 17/17 动作冷审计，但每 5 ms 状态足底回放出现 **65.63%** 利用率峰值，超过 50% 筛查门槛。本修正版本完成从接近、四手抓取、约 6° 转动、放回、张手到撤离的全程原生闭环；独立冷审计 **17/17** 通过，每 5 ms 保存状态的足底审计峰值 **28.29%**，无超门槛样本。转角 **5.996°**，100 ms 手部滑移峰值 **0.105 mm**，累计滑移 **1.335 mm**，指尖法向力峰值 **7.52 N**，模型机器人几何穿透峰值 **0.233 mm**，身体关节 5 ms 差分加速度峰值 **75.63 rad/s²**。

该结果是**一个离散模型条件下的仿真候选**。2 ms 是指令更新后的简化延迟，不包含传感、网络、驱动器及状态估计延迟；保存状态间的接触峰值也未验证。尚无实验室四只手的实际轴映射、驱动电流与关节跟踪，以及桌体和足底参数，因此不能下发实机或宣称实机动作质量。审计、轨迹、模型与控制器哈希见 `TURN_MU07_MASS12_FOOTCAP35_DELAY2MS_CANDIDATE_MANIFEST.json`。

把相同 35% 约束扩展至接近阶段并测试 5 ms 指令延迟时，约 6.395 s 仍因机器人右脚对地面穿透 **1.369 mm** 而失败。因此本候选只覆盖已测试的 2 ms 条件，没有已验证的 5 ms 容错。
